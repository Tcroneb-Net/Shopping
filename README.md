## 📖 About the Project

**SOLE & STYLE** is a clean, modern ecommerce storefront concept built to make browsing everyday fashion simple and enjoyable.

Explore sneakers, clothing, and accessories in one place. Search the collection, filter by category, save favorites, and manage items in an interactive shopping bag.

The project currently runs as a front-end demo using HTML, CSS, and vanilla JavaScript. It does not yet process real payments or store orders on a server.

## ✨ Features

- 🛒 **Interactive shopping bag** — Add products, remove them, and adjust quantities.
- ❤️ **Wishlist** — Save and unsave favorite products during your session.
- 🔎 **Product search** — Find items by product name or category.
- 🏷️ **Category filters** — Browse shoes, clothing, accessories, or the full collection.
- ↕️ **Sorting** — Sort products by price or name.
- 💵 **Live subtotal** — Cart totals update when quantities change.
- 📱 **Responsive layout** — Designed for desktop, tablet, and mobile screens.
- 🎨 **Modern storefront** — Product cards, promotional hero section, and slide-out cart.

## 🚀 Getting Started

### Option 1: Download and open

1. Download or clone this repository.
2. Open the project folder.
3. Open `sole_and_style_store.html` in a modern web browser.

### Option 2: Clone with Git

```bash
git clone https://github.com/Tcroneb-Net/Shopping.git
cd sole-and-style
```

Then open `sole_and_style_store.html` in your browser.

> Replace `YOUR-USERNAME` with your GitHub username. Product images are loaded from Unsplash, so an internet connection is needed to display them.

## 🧪 Testing the Store

Try these actions after opening the website:

1. Browse the product collection.
2. Search for a product by name.
3. Switch between category filters.
4. Change the sorting option.
5. Add one or more products to your bag.
6. Increase or decrease product quantities.
7. Remove a product from the bag.
8. Check that the subtotal updates.
9. Resize the browser to check the mobile layout.

The current cart and wishlist are front-end interactions. They are not saved to a customer account or database.
