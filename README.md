SOLE & STYLE is a modern, stylish, and responsive ecommerce storefront designed to make online shopping simple, enjoyable, and accessible.

Discover sneakers, clothing, and accessories in one place. Browse products, search your favorites, manage your shopping bag, and enjoy a clean shopping experience.

---

✨ Features

- 🛒 Shopping Cart — Add and remove products with live quantity updates.
- ❤️ Wishlist — Save your favorite products.
- 🔍 Product Search — Quickly find products.
- 🏷️ Category Filtering — Browse shoes, clothing, and accessories.
- ↕️ Product Sorting — Sort by price or product name.
- 💰 Dynamic Pricing — Automatically calculate cart subtotals.
- 📱 Responsive Design — Optimized for desktop, tablet, and mobile.
- 🎨 Modern UI — Clean layouts, stylish product cards, and smooth interactions.
- ⚡ Lightweight — Built with HTML, CSS, and vanilla JavaScript.

🚀 Getting Started

1. Clone the repository

git clone https://github.com/YOUR-USERNAME/sole-and-style.git

2. Enter the project directory

cd sole-and-style

3. Run the website

Open "sole_and_style_store.html" in your browser.

No complicated installation or dependencies required!
